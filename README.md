# Invincible Worker Bots: Updated

Makes construction and logistic robots immune to damage, allowing them to repair defenses and cross dangerous areas without being destroyed.

This fork retains the original robot protection behavior for Factorio 2.1.24.

Requires Factorio 2.1.24 or later. Disable `invincible-worker-bots` before enabling this fork. Required content and optional integrations are listed in the mod dependencies.
